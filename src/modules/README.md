# Módulos de negócio

Cada módulo deve concentrar suas rotas, casos de uso, validações e acesso a dados. Novos módulos devem respeitar o escopo por `school_id` e a autorização definida na documentação arquitetural.

Módulos previstos para o MVP:

- auth
- schools
- users
- students
- guardians
- enrollments
- renewals
- audit
